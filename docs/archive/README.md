# Historical documentation archive

These documents describe earlier prototypes and review rounds. They are kept for provenance and for understanding why decisions were made.

They may contain obsolete statements, including “Root unavailable”, “no remote CI” or older version numbers. Do not use them as a description of the current app. Use `docs/STATUS.md`, `docs/ARCHITECTURE.md` and `docs/CHANGELOG.md` instead.

Internal links in archived files may point to the old `docs/` layout; repair links only when it adds historical clarity, without rewriting the historical conclusions.
