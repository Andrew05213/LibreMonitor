# v0.3.1 icon UI redesign

This documents the 0.3.x redesign; 0.3.0 and 0.3.1 were same-day iterations.

The primary screens were rebuilt as an icon-led dashboard. Data collection, permissions, history schema/CSV and Root behavior are unchanged.

## Visual system

- Dark-first deep-green canvas with mint primary and warm amber accent; light theme uses the same hierarchy.
- Header: app mark, title, and a live/stale/waiting chip; bottom navigation uses Dashboard/Battery/Settings icons.
- Overview: CPU hero card with a circular gauge, temperature and per-core progress rows; icon metric tiles for CPU temperature, battery, memory and storage; icon sections for network and GPU.
- Battery: large battery percentage with circular gauge, then voltage/current/power/temperature/health/capacity/cycle tiles, followed by the real-history chart and record controls.
- Settings: icon section headers, refresh chips, icon switches, export/clear actions, Root and device information.
- Material Rounded icons via `androidx.compose.material:material-icons-extended`; no decorative sample data.

## Device smoke check

Observed on the OnePlus PJE110 / Android 17 / KernelSU device after installing 0.3.1:

- CPU hero: 42.6%, 64.8°C; per-core CPU0–CPU7 bars/frequencies populated.
- Battery page: 100%, 4.44V, -1mA, -0.00W, 34.5°C, GOOD, capacity health 82.4%, design 5500mAh, full 4530mAh, remaining 4376mAh, 883 cycles, AC.
- Root and one-key permissions were already active; no permission dialog was skipped.

The screenshots are visual smoke evidence, not a claim of cross-device layout or accessibility validation. Large font/TalkBack/320dp and light-theme testing remain open.
